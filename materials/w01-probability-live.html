Why the event collection must be closed

If we can ask whether A occurs, what related questions should the model also describe?

Use the complement and “at least one of” examples for intuition. Then state the closure conditions. The exact sigma-algebra definition and the finite/cofinite counterexample are in the main notes, §4. The probability axioms are in main notes §5. Do not derive measure-theoretic constructions here.

Suggested working:

Whether AA does not occur: the complement AcA^c.

Whether at least one of A1,A2,…A_1,A_2,\ldots occurs: the union ⋃nAn\bigcup_n A_n.

An event collection containing Ω\Omega and closed under complements and countable unions is a σ-algebra.

For a finite model we ordinarily use all subsets; this collection satisfies these requirements.

The probability rules

Complements let us ask what cannot occur; countable unions let us ask whether at least one of a list of events occurs. Once these questions are events, what rules should their probabilities obey?

Keep the distinction explicit: complement and countable-union closure belong to the σ\sigma-algebra; these three conditions are the probability axioms. The complement rule P(Ac)=1−P(A)P(A^c)=1-P(A) follows because AA and AcA^c partition Ω\Omega.

Suggested working:

Kolmogorov’s axioms constrain PP on the event collection ℱ\mathcal F:

  1. Nonnegativity: P(A)≥0P(A)\ge0 for every A∈ℱA\in\mathcal F.
  2. Normalization: P(Ω)=1P(\Omega)=1; an experiment produces an outcome in Ω\Omega.
  3. Countable additivity: if A1,A2,…∈ℱA_1,A_2,\ldots\in\mathcal F are pairwise disjoint, then

P(⋃n=1∞An)=∑n=1∞P(An).P\!\left(\bigcup_{n=1}^{\infty}A_n\right)=\sum_{n=1}^{\infty}P(A_n).

The union is “at least one”; disjointness prevents double counting. Complements and countable unions define the event collection; these three axioms govern its probabilities.

A random variable and a probability measure

For outcomes PP, PF, FP, FF with probabilities 0.72, 0.08, 0.18, 0.02, let X count failures. Find X(PF) and P({PF,FP}). What does each map take as input?

Allow students to work before showing the completed calculation. Discuss the interpretation before advancing.

Suggested working:

Despite its name, XX is not itself a random rule. Once the experiment and recording rule are fixed, XX is a fixed function on the set of outcomes. The random outcome supplied to it gives its value a distribution. It maps each outcome to a real number:

X:Ω→ℝ,ω↦X(ω).X:\Omega\to\mathbb R,\qquad \omega\mapsto X(\omega).

Precisely, XX is measurable when, for every Borel set B⊆ℝB\subseteq\mathbb R, the inverse image

X−1(B)={ω∈Ω:X(ω)∈B}X^{-1}(B)=\{\omega\in\Omega:X(\omega)\in B\}

belongs to ℱ\mathcal F. Here X(PF)=1X(PF)=1.

Probability is the set function P:ℱ→[0,1]P:\mathcal F\to[0,1]: it maps an event to a number in the unit interval. Thus P({PF,FP})=0.08+0.18=0.26P(\{PF,FP\})=0.08+0.18=0.26. Ask students to apply these steps to one inspection problem and one continuous measurement model, rather than recite the list.

Suggested working:

Specify the experiment and the sampling rule.

Write the event as a set or an equivalent numerical condition.

Use probabilities consistent with the sampling rule. Counting requires equally likely outcomes.

For a transformation, carry the distribution with it and check the inverse image of the event.

Further reading

Use the main notes for additional worked problems and the supplement for the formal development.

Allow students to work before showing the completed calculation. Discuss the interpretation before advancing.

Suggested working:

Jay L. Devore, Probability and Statistics for Engineering and the Sciences, 9th edition, Chapters 2–4: sample spaces and events, probability, random variables and their distributions. The publisher’s table of contents is provided for reference.

Krishna Jagannathan, Probability Foundations for Electrical Engineers, Chapters 1, 4, and 11. The examples here are stipulated for this course.
