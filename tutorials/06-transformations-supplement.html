01.6 supplement · Change of variables and induced laws

Main lecture 01.6

1. The general construction does not require a density

For a measurable map g:ℝm→ℝkg:\mathbb R^m\to\mathbb R^k and random vector 𝑿\mathbf X, the law of 𝒀=g(𝑿)\mathbf Y=g(\mathbf X) is P𝒀(B)=P𝑿(g−1(B))P_{\mathbf Y}(B)=P_{\mathbf X}(g^{-1}(B)). Preimages preserve complements and countable unions, so this assignment is a probability measure on Borel sets. It remains valid for discrete, continuous, mixed and singular laws. The notation g−1(B)g^{-1}(B) means a set preimage, not necessarily a functional inverse.

If 𝑿\mathbf X has a density, integrate it over the preimage. A transformed density exists only if the new law is absolutely continuous with respect to the appropriate volume measure. For instance, (X,X)(X,X) lives on a diagonal and has no ordinary planar density even when XX has a density on the line.

2. Change-of-variables theorem for densities

Let U,V⊆ℝmU,V\subseteq\mathbb R^m be open and let g:U→Vg:U\to V be a C1C^1 diffeomorphism. Let 𝑿\mathbf X have density ff with P(𝑿∈U)=1P(\mathbf X\in U)=1. Write h=g−1h=g^{-1}. By the multivariable integration theorem, for every Borel B⊆VB\subseteq V,

P(g(𝑿)∈B)=∫g−1(B)f(𝒙)d𝒙=∫Bf(h(𝒚))|det⁡Dh(𝒚)|d𝒚.\begin{aligned} P(g(\mathbf X)\in B) &=\int_{g^{-1}(B)}f(\mathbf x)d\mathbf x\\ &=\int_B f(h(\mathbf y))|\det Dh(\mathbf y)|d\mathbf y. \end{aligned}

The integrand is therefore a density on VV, extended by zero elsewhere. Its integral is 1 by taking B=VB=V. The inverse function theorem gives Dh(g(𝒙))=[Dg(𝒙)]−1Dh(g(\mathbf x))=[Dg(\mathbf x)]^{-1}, so the inverse determinant is the reciprocal of the forward determinant in absolute value. Absolute value accounts for orientation reversal.

A null set excluded from the original support causes no loss of probability. When a transformation is one-to-one only on separate regions, partition the original support into those regions, apply the theorem on each, and add their densities on overlapping image regions. This proves the finite-branch formula. Critical sets with positive probability cannot simply be discarded.

3. Auxiliary-variable construction and convolution

If (X,Y)(X,Y) has density fX,Yf_{X,Y}, the linear map (x,y)↦(s,v)=(x+y,x)(x,y)\mapsto(s,v)=(x+y,x) is invertible on the plane with inverse (v,s−v)(v,s-v) and absolute inverse determinant 1. Hence fS,V(s,v)=fX,Y(v,s−v)f_{S,V}(s,v)=f_{X,Y}(v,s-v) and marginalization yields fS(s)=∫fX,Y(v,s−v)dvf_S(s)=\int f_{X,Y}(v,s-v)dv. Nonnegativity permits the iterated integral by Tonelli’s theorem. Product convolution is obtained only under independence.

For a signed difference R=Y−XR=Y-X, take V=XV=X: fR(r)=∫fX,Y(v,v+r)dvf_R(r)=\int f_{X,Y}(v,v+r)dv. Under iid densities hh, symmetry gives fR(r)=fR(−r)f_R(r)=f_R(-r); folding yields f|R|(d)=2fR(d)f_{|R|}(d)=2f_R(d) for d>0d>0, provided no atom at zero is omitted. The meeting model has none because the diagonal has probability zero.

4. Inverse-CDF generation

For a CDF FF, let Q(u)=inf⁡{x:F(x)≥u}Q(u)=\inf\{x:F(x)\ge u\}, 0<u<10<u<1. The CDF properties imply Q(u)≤xQ(u)\le x if and only if u≤F(x)u\le F(x). Thus if U∼U(0,1)U\sim U(0,1),

P(Q(U)≤x)=P(U≤F(x))=F(x).P(Q(U)\le x)=P(U\le F(x))=F(x).

This argument handles jumps and flat portions; ordinary functional inversion is not required. Uniform endpoint values have probability zero in the mathematical model, but implementations of logarithmic generators must avoid evaluating log⁡0\log0.

5. Polar transformation and standard-normal generation

Let U1,U2U_1,U_2 be independent uniform variables on (0,1)(0,1). Set R=−2log⁡U1R=\sqrt{-2\log U_1} and Θ=2πU2\Theta=2\pi U_2. For r≥0r\ge0, P(R≤r)=1−e−r2/2P(R\le r)=1-e^{-r^2/2}, so fR(r)=re−r2/2f_R(r)=re^{-r^2/2} for r>0r>0. The angle is uniform on (0,2π)(0,2\pi) and independent of RR.

Set Z1=Rcos⁡ΘZ_1=R\cos\Theta, Z2=Rsin⁡ΘZ_2=R\sin\Theta. Away from a null origin and angle cut, the polar-to-Cartesian absolute determinant is rr. Hence

fZ1,Z2(z1,z2)=re−r2/22π1r=12πe−(z12+z22)/2=ϕ(z1)ϕ(z2).f_{Z_1,Z_2}(z_1,z_2)=\frac{re^{-r^2/2}}{2\pi}\frac1r =\frac1{2\pi}e^{-(z_1^2+z_2^2)/2}=\phi(z_1)\phi(z_2).

The outputs are independent standard normals. This derivation explains the Box–Muller construction used for the fixed simulated points in Lecture 01.7’s visual demonstration. Pseudorandom implementation is a computational approximation to the ideal independent-uniform inputs.
