Questions for this lecture

A manufacturing supervisor asks how many components in a tested batch need replacement. An accountant asks how often an invoice contains a discrepancy. An engineer asks whether two sensors both meet their tolerances. A logistics planner asks whether delayed deliveries are more common on longer routes. Each question concerns a numerical recording of an outcome, but the required distribution differs.

We will learn to:

  • construct and use a probability mass function (PMF) for discrete values;
  • calculate probabilities from a probability density function (PDF) for continuous measurements;
  • use a cumulative distribution function (CDF) for either type;
  • describe two quantities with a joint distribution;
  • obtain marginal distributions by adding or integrating over the other quantity;
  • obtain conditional distributions by restricting to the information given and normalizing;
  • check whether independence is justified.

The treatment uses counting, sums, areas and elementary integrals. Technical proofs and exceptional cases are in the supplement. All numerical records and models below are hypothetical or stipulated for teaching. Worked examples include calculations; independent exercises at the end do not include answers.

NoteRecall the probability model: outcomes, events and weights

An outcome is one result of the experiment; an event is a set of outcomes. The model is (Ω,ℱ,P)(\Omega,\mathcal F,P).

The power set 𝒫(Ω)=2Ω\mathcal P(\Omega)=2^\Omega is the collection of all subsets of Ω\Omega. We use it as the event collection for our finite examples. A sigma-algebra is an event collection containing Ω\Omega and closed under complements and countable unions; it consequently contains the empty set and countable intersections too. Thus the model can express “not,” “at least one” and “all” for the relevant lists of events.

Kolmogorov’s axioms say that probabilities are nonnegative, the whole space has probability 1, and probabilities add over countably many pairwise disjoint events. They do not require equal outcome weights. A random variable assigns a number to an outcome; its PMF collects the probability weights of all outcomes producing each numerical value.

See the definition boxes in Lecture 01.1 for small examples and the distinction between an event collection and a probability assignment.

1. From selected records to a discrete distribution

Worked example 1: replacement counts in inspected batches

A workshop inspects ten batches of electrical connectors, each containing the same number of connectors. Inspectors record how many connectors in each batch require replacement. A supervisor wants to know how often a batch in this completed inspection needs at least two replacements, because such batches require an additional quality review.

The experiment is to select one of the ten batch IDs uniformly, so each ID has probability 1/101/10. These are fixed inspection records:

Batch ID b1b_1 b2b_2 b3b_3 b4b_4 b5b_5 b6b_6 b7b_7 b8b_8 b9b_9 b10b_{10}
Replacements 0 0 0 0 1 1 1 2 2 3

What is the probability that the selected batch requires the additional review?

Three batch IDs meet the condition, so the probability is 3/103/10. Let X(bi)X(b_i) be the recorded number of replacements. The outcomes are batch IDs; XX records a number for the selected ID. Collecting IDs with the same number gives:

xx 0 1 2 3
Number of IDs 4 3 2 1
P(X=x)P(X=x) 0.40.4 0.30.3 0.20.2 0.10.1

Thus P(X≥2)=0.2+0.1=0.3P(X\ge2)=0.2+0.1=0.3. The four numerical values are not equally likely even though the ten batch IDs are.

The PMF after the calculation

NoteDefinition: a discrete random variable and its PMF

A random variable is discrete when its values lie in a finite or countably infinite set with probability 1. Its probability mass function is

pX(x)=P(X=x).p_X(x)=P(X=x).

A valid PMF satisfies

pX(x)≥0,∑xpX(x)=1.p_X(x)\ge0,\qquad \sum_x p_X(x)=1.

For a set of values AA,

P(X∈A)=∑x∈ApX(x).P(X\in A)=\sum_{x\in A}p_X(x).

The sum runs over possible values; values outside the stated range have mass zero. For the batch-inspection example, the masses sum to 0.4+0.3+0.2+0.1=10.4+0.3+0.2+0.1=1. The distribution describes uniform selection from these fixed records. The worked appendix explicitly constructs a finite probability triplet and the event groups behind a PMF using a separate ticket dataset. A forecast for future production requires assumptions about whether the production process and inspection criteria remain comparable.

Worked example 1a: a deliberately nonuniform die

A stipulated six-sided device has outcome weights proportional to 1,1,2,2,3,31,1,2,2,3,3 for faces 1 through 6. Let DD record the face. The weights sum to 12, so

dd 1 2 3 4 5 6
pD(d)p_D(d) 1/121/12 1/121/12 2/122/12 2/122/12 3/123/12 3/123/12

All masses are nonnegative and sum to 1. For the two largest faces,

P(D≥5)=312+312=12.P(D\ge5)=\frac3{12}+\frac3{12}=\frac12.

Counting two favorable faces out of six would give 1/31/3, which is wrong for this specified mechanism. We must add their weights. A finite sample space and the full power set remain valid when the outcome weights are unequal.

Worked example 1b: number of failed electrical supplies

An equipment engineer is assessing a device with two power supplies. Either supply can keep the device running alone; the device loses power only if both fail. Let NN count failed supplies at a specified inspection time. The engineer wants to distinguish the chance of any failed supply, which triggers maintenance, from the chance of losing power. Stipulate the joint states and their probabilities below. These are model weights, not an assumption that all four states are equally likely.

State of supplies 1 and 2 Both work Only supply 1 fails Only supply 2 fails Both fail
Probability 0.720.72 0.180.18 0.080.08 0.020.02
Failure count NN 0 1 1 2

To obtain the PMF of the number of failures, combine the weights of states producing the same count:

pN(0)=0.72,pN(1)=0.18+0.08=0.26,pN(2)=0.02.p_N(0)=0.72,\qquad p_N(1)=0.18+0.08=0.26,\qquad p_N(2)=0.02.

Thus P(N≥1)=0.26+0.02=0.28=1−0.72P(N\ge1)=0.26+0.02=0.28=1-0.72. Neither counting three failure states out of four nor assigning 1/31/3 to each possible count is justified. The chance of losing power is instead P(N=2)=0.02P(N=2)=0.02. These two events answer different operational questions. Independence of the two supplies is not assumed; their joint state probabilities have been supplied directly.

TipTwo reasons a discrete distribution may be nonuniform

In the batch inspection, equally likely IDs produce unequal PMF masses because different numbers of batches have each replacement count. In the supply model, the elementary states already have unequal weights, and states with the same count have their weights added. In both cases,

P(X=x)=∑ω:X(ω)=xP({ω})P(X=x)=\sum_{\omega:X(\omega)=x}P(\{\omega\})

for the finite experiments considered here. Counting is the special case where every elementary weight is 1/|Ω|1/|\Omega|.

Worked example 2: accounting discrepancy counts

An accounts team has completed a review of twelve invoices. A discrepancy is a recorded mismatch in a field such as the billed quantity or agreed price; an invoice can contain more than one. Seven invoices have no discrepancy, three have one, and two have two. The team asks: if one invoice is selected uniformly from this reviewed set, what is the chance it needs correction?

Let DD count discrepancies on the selected invoice. Each invoice ID has probability 1/121/12, so

pD(0)=712,pD(1)=312,pD(2)=212.p_D(0)=\frac7{12},\qquad p_D(1)=\frac3{12},\qquad p_D(2)=\frac2{12}.

The probability of at least one discrepancy is

P(D≥1)=312+212=1−712=512.P(D\ge1)=\frac3{12}+\frac2{12}=1-\frac7{12}=\frac5{12}.

There are seven discrepancy instances across the twelve invoices: three on the one-discrepancy invoices and four on the two-discrepancy invoices. Selecting an invoice uniformly is a different experiment from selecting one of those seven instances uniformly. State the sampling unit before choosing the denominator.

Worked example 2a: financial loss records

A finance team reviews eight completed foreign-currency settlements. Relative to its budgeted exchange rate, four settlements have recorded loss ₹0, three have ₹50, and one has ₹200; none has a gain in this small teaching dataset. The reviewer selects one settlement ID uniformly. Let LL be its recorded loss in rupees. What fraction of these settlements lost more than ₹50, and how does the answer change if the threshold includes ₹50? The PMF is pL(0)=4/8p_L(0)=4/8, pL(50)=3/8p_L(50)=3/8 and pL(200)=1/8p_L(200)=1/8, with zero mass elsewhere. Consequently P(L>50)=1/8P(L>50)=1/8, whereas P(L≥50)=4/8P(L\ge50)=4/8. The currency values are the random-variable values; the fractions are their probabilities. This is selection from fixed records, not a forecast of future losses.

Worked example 3: a countably infinite PMF

For a stipulated IT retry model, let NN be the number of failures before the first successful attempt, with

pN(n)=34(14)n,n=0,1,2,….p_N(n)=\frac34\left(\frac14\right)^n,\qquad n=0,1,2,\ldots.

This model corresponds to independent attempts with success probability 3/43/4 on every attempt, continued until success. Here independence means that learning the outcomes of earlier attempts does not change the stipulated success probability of the next attempt. Section 7 gives the formal independence condition. There is no fixed maximum count. The geometric-series identity verifies the PMF:

∑n=0∞pN(n)=3411−1/4=1.\sum_{n=0}^{\infty}p_N(n)=\frac34\frac1{1-1/4}=1.

At least two failures before success has probability

P(N≥2)=1−pN(0)−pN(1)=1−34−316=116.P(N\ge2)=1-p_N(0)-p_N(1) =1-\frac34-\frac3{16}=\frac1{16}.

Actual retries may have changing success chances or a retry limit; those require a different model. The example shows that “discrete” does not mean “only finitely many values.”

2. Accumulated probability: the CDF

Worked example 4: a replacement-count threshold

Return to the ten inspected batches in Example 1, with XX the replacement count. Suppose the workshop can replace at most one connector per batch during its routine processing slot. What proportion of the recorded batches fit within that capacity? The batches with zero or one replacement qualify, giving 4/10+3/10=0.74/10+3/10=0.7.

If capacity changes, we need the probability that XX is at most each possible threshold. For thresholds 0, 1 and 2 the answers are 0.40.4, 0.70.7 and 0.90.9. A single function can collect these answers.

The cumulative distribution function of any real-valued random variable is

FX(x)=P(X≤x).F_X(x)=P(X\le x).

Here it is the step function

FX(x)={0,x<0,0.4,0≤x<1,0.7,1≤x<2,0.9,2≤x<3,1,x≥3.F_X(x)=\begin{cases} 0,&x<0,\\ 0.4,&0\le x<1,\\ 0.7,&1\le x<2,\\ 0.9,&2\le x<3,\\ 1,&x\ge3. \end{cases}

For example, FX(1.5)=0.7F_X(1.5)=0.7: counts 0 and 1 are included. The jump at 2 is 0.20.2, the probability of exactly two replacements. The CDF is nondecreasing, right-continuous, and approaches 0 and 1 at the two ends of the real line.

The interval rule is

P(a<X≤b)=FX(b)−FX(a),a<b.P(a<X\le b)=F_X(b)-F_X(a),\qquad a<b.

Consequently P(1<X≤3)=1−0.7=0.3P(1<X\le3)=1-0.7=0.3. Including 1 changes the answer: P(1≤X≤3)=0.3+0.2+0.1=0.6P(1\le X\le3)=0.3+0.2+0.1=0.6. At a value carrying positive probability, endpoint wording matters.

Stopping point 1. Work several PMF and CDF questions before introducing density. Learners should be able to distinguish a possible value from its probability and explain which values a threshold includes.

From counting outcomes to measuring length and area

Worked bridge: uniform grid selection and a uniform location

Divide a rectangular field into 10 rows and 10 columns of equal-area cells. The leftmost four columns are marked for inspection. Select one of the 100 cell IDs uniformly. Forty IDs are marked, so

P(marked cell)=40100=0.4.P(\text{marked cell})=\frac{40}{100}=0.4.

Now describe a different experiment: select a location uniformly by area over the field. The marked region occupies four tenths of the field’s width and its full height. Its area is therefore four tenths of the total, giving

P(marked location)=marked areatotal area=0.4.P(\text{marked location})=\frac{\text{marked area}}{\text{total area}}=0.4.

The answers agree because the cells have equal areas and the region is exactly their union. Cell selection produces an ID; location selection produces a point. If cells had unequal areas, uniform selection of their IDs would not be uniform location selection. This is the same distinction as selecting farm plots by ID or by area in Lecture 01.1.

NoteWhat replaces counting in a continuous uniform model?

For equally likely finite outcomes, probability is the fraction of total count:

P(E)=#E#Ω.P(E)=\frac{\#E}{\#\Omega}.

For a uniform location in a finite interval or region, probability is the fraction of total length or area:

P(E)=length⁡(E)length⁡(Ω),P(E)=area⁡(E)area⁡(Ω),P(E)=\frac{\operatorname{length}(E)}{\operatorname{length}(\Omega)}, \qquad P(E)=\frac{\operatorname{area}(E)}{\operatorname{area}(\Omega)},

respectively, for the ordinary measurable events used here and positive finite total length or area. These are different models sharing the idea of normalizing the appropriate size to total probability 1.

We do not count the individual points in a continuous interval or region. Each point has zero length or area, while an interval or region can have positive size. Countable additivity does not instruct us to sum over uncountably many singleton points.

For a curved marked region, an increasingly fine equal-area grid can approximate its area using the fraction of marked cells. For ordinary regions whose boundaries have area zero, the uncertainty from cells touching the boundary vanishes as the grid is refined. The limiting area is the quantity used in the continuous model; a finite grid remains a discrete approximation.

TipBeyond uniformity: weights become density times width or area

In a discrete model we add probability weights, P(X∈A)=∑x∈ApX(x)P(X\in A)=\sum_{x\in A}p_X(x). In a density model, a small interval near xx has probability approximately fX(x)Δxf_X(x)\,\Delta x when the density varies little across it. Adding these small contributions leads to the integral ∫AfX(x)dx\int_A f_X(x)dx.

For a location in a plane, a small cell contributes approximately fX,Y(x,y)ΔxΔyf_{X,Y}(x,y)\,\Delta x\,\Delta y. Integrating these contributions gives a region’s probability. Uniform density makes this proportional to geometric area; a varying density gives different weights to equal-area cells.

For example, on the unit interval the uniform density gives P(X≤0.4)=0.4P(X\le0.4)=0.4. Under the stipulated nonuniform density fX(x)=2xf_X(x)=2x on (0,1)(0,1), the same event instead has probability ∫00.42xdx=0.16\int_0^{0.4}2x\,dx=0.16. Its length has not changed; the model’s probability weights have.

3. Continuous measurements: density and area

Worked example 5: voltage tolerance

An engineer checks a voltage meter against a known reference. Define its error VV as the displayed voltage minus the reference voltage: a negative value means the meter reads too low. A reading meets the specified tolerance when its error is between −0.04-0.04 and 0.040.04 volts.

For this simplified measurement model, stipulate that VV is uniform on [−0.1,0.1][-0.1,0.1] volts. Uniformity means equal-length error intervals within this range have equal probabilities. What is the probability that a reading meets the tolerance, that is, |V|≤0.04|V|\le0.04?

The acceptable interval has length 0.080.08 V and the full interval has length 0.20.2 V, giving

P(|V|≤0.04)=0.080.2=0.40.P(|V|\le0.04)=\frac{0.08}{0.2}=0.40.

Its density is

fV(v)={5,−0.1≤v≤0.1,0,otherwise.f_V(v)=\begin{cases}5,&-0.1\le v\le0.1,\\0,&\text{otherwise}.\end{cases}

The density height has units V−1^{-1}. Multiplying by interval width gives the probability 5(0.08)=0.405(0.08)=0.40. A density height can exceed 1; the total area must be 1. Here it is 5(0.2)=15(0.2)=1.

The PDF after the calculation

NoteDefinition and interpretation: a probability density function

For the continuous models in this lecture, a probability density function fXf_X is nonnegative and satisfies

∫−∞∞fX(x)dx=1,P(a≤X≤b)=∫abfX(x)dx.\int_{-\infty}^{\infty}f_X(x)\,dx=1,\qquad P(a\le X\le b)=\int_a^b f_X(x)\,dx.

Probability is area under the density, not its height at a point. In a density model P(X=x)=0P(X=x)=0 for every individual xx, so including or excluding interval endpoints does not change the probability. A rounded measurement is different: a display reading usually represents a small interval of possible underlying values.

In this lecture “continuous” refers to variables described by a density. Mixed distributions and a qualification to this terminology are discussed in the supplement.

Worked example 6: a nonuniform latency density

An IT team is examining the time from sending a database request to receiving its response. For this teaching model, every request completes within two seconds, and longer times within this range have greater probability density. Let TT be the response time in seconds. The team wants the probability of missing a one-second response target. Stipulate the density

fT(t)={t/2,0≤t≤2,0,otherwise.f_T(t)=\begin{cases}t/2,&0\le t\le2,\\0,&\text{otherwise}.\end{cases}

Here tt is the numerical latency in seconds; dimensionally the coefficient 1/21/2 has units s−2^{-2}, so the density has units s−1^{-1}.

First verify the model:

∫02t2dt=[t24]02=1.\int_0^2\frac t2\,dt=\left[\frac{t^2}{4}\right]_0^2=1.

What is the chance of latency exceeding 1 second?

P(T>1)=∫12t2dt=[t24]12=34.P(T>1)=\int_1^2\frac t2\,dt =\left[\frac{t^2}{4}\right]_1^2=\frac34.

The interval (1,2](1,2] is half the full interval’s length, but contains three quarters of the probability. Ratios of lengths apply to a uniform density, not to every continuous model.

The CDF is

FT(t)={0,t<0,t2/4,0≤t≤2,1,t>2.F_T(t)=\begin{cases}0,&t<0,\\t^2/4,&0\le t\le2,\\1,&t>2.\end{cases}

This follows by integrating from 0 to tt. It also gives P(0.5<T≤1.5)=FT(1.5)−FT(0.5)=(2.25−0.25)/4=1/2P(0.5<T\le1.5)=F_T(1.5)-F_T(0.5)=(2.25-0.25)/4=1/2. For a density model, FT(t)=∫−∞tfT(u)duF_T(t)=\int_{-\infty}^t f_T(u)\,du; where the CDF is differentiable, its derivative gives a version of the density. Here FT′(t)=fT(t)F_T'(t)=f_T(t) except at t=2t=2.

Worked example 7: a rounded display value

In the same model, a system displays latency rounded to the nearest tenth of a second. Ignoring tie endpoints, a displayed value 1.0 represents 0.95≤T<1.050.95\le T<1.05. Thus

P(display=1.0)=1.052−0.9524=0.05.P(\text{display}=1.0)=\frac{1.05^2-0.95^2}{4}=0.05.

This does not conflict with P(T=1)=0P(T=1)=0. The displayed variable is a discrete recording of the continuous latency.

4. Two recordings on the same outcome: a joint PMF

Worked example 8: tool retries and an evaluation result

An evaluation team has completed 20 runs of an AI assistant that retrieves information through an external tool. A tool retry is an additional attempt after a tool call fails; passing means the final answer satisfies a fixed reviewer checklist. A run can recover after a retry, and a run without retries can still give an incorrect answer.

The team wants to describe how retries and final results occur together. Select one of these 20 run IDs uniformly; the outcome is the entire selected run, with both of its recorded quantities:

  • XX: number of tool retries, taking values 0, 1 or 2;
  • YY: evaluation result, with 1 for pass under a fixed review protocol and 0 for fail.

The hypothetical counts are:

Retry count XX Y=0Y=0 Y=1Y=1 Row total
0 2 8 10
1 3 3 6
2 3 1 4
Column total 8 12 20

What is the probability that a selected run passes and has at least one retry? The relevant cells contain 3+1=43+1=4 IDs, so it is 4/20=0.24/20=0.2.

Both numbers are recorded on the same selected run. The joint PMF is

pX,Y(x,y)=P(X=x,Y=y),p_{X,Y}(x,y)=P(X=x,Y=y),

where the comma means “and.” Divide each cell count by 20:

pX,Y(x,y)p_{X,Y}(x,y) y=0y=0 y=1y=1
x=0x=0 0.100.10 0.400.40
x=1x=1 0.150.15 0.150.15
x=2x=2 0.150.15 0.050.05

The entries are nonnegative and add to 1. Probabilities of conditions on the pair are found by summing the corresponding cells. For instance,

P(X=0 or Y=1)=0.10+0.40+0.15+0.05=0.70.P(X=0\text{ or }Y=1)=0.10+0.40+0.15+0.05=0.70.

The cell (0,1)(0,1) is included once. These probabilities describe uniform selection from the fixed audit. They do not establish that retries cause failure or predict future agent performance.

5. Marginals: retain one recording

Worked example 9: retry counts without the evaluation result

The evaluation team now asks a resource-planning question: how many retries occurred, regardless of whether the final answer passed? A failed run still consumes tool calls, so both result columns must contribute. In Example 8, add across both result columns:

pX(0)=0.10+0.40=0.50,pX(1)=0.15+0.15=0.30,pX(2)=0.15+0.05=0.20.p_X(0)=0.10+0.40=0.50,\quad p_X(1)=0.15+0.15=0.30,\quad p_X(2)=0.15+0.05=0.20.

Adding down rows gives pY(0)=0.40p_Y(0)=0.40 and pY(1)=0.60p_Y(1)=0.60.

These are the marginal PMFs:

pX(x)=∑ypX,Y(x,y),pY(y)=∑xpX,Y(x,y).p_X(x)=\sum_y p_{X,Y}(x,y),\qquad p_Y(y)=\sum_x p_{X,Y}(x,y).

A marginal includes all possible values of the other recording. It does not require independence. For example, P(X≥1)=0.30+0.20=0.50P(X\ge1)=0.30+0.20=0.50 and P(Y=1)=0.60P(Y=1)=0.60.

Worked example 9a: delivery delays and route type

A distributor reviews 30 completed deliveries. Each delivery is classified as local or regional; “late” means it arrived after the promised delivery time. Select one delivery ID uniformly from these records. Let R=0R=0 indicate a local route and R=1R=1 a regional route; let D=1D=1 indicate late arrival and D=0D=0 on-time arrival.

Route On time, D=0D=0 Late, D=1D=1 Total
Local, R=0R=0 16 4 20
Regional, R=1R=1 6 4 10
Total 22 8 30

The planner asks three questions. What is the chance of selecting a late regional delivery? How often is a delivery late regardless of route? Among regional deliveries, how often is it late?

The joint probability uses one cell and all 30 deliveries:

P(R=1,D=1)=rac430=rac215.P(R=1,D=1)= rac4{30}= rac2{15}.

The marginal probability of lateness combines both route types:

P(D=1)=rac430+rac430=rac830=rac415.P(D=1)= rac4{30}+ rac4{30}= rac8{30}= rac4{15}.

For the third question, only the ten regional deliveries are relevant. Four are late, so the probability within that group is 4/10=0.44/10=0.4. This previews a conditional probability, developed in Section 6. For local deliveries the corresponding fraction is 4/20=0.24/20=0.2. Equal numbers of late deliveries do not imply equal late-arrival rates when group sizes differ.

The other marginal is P(R=0)=20/30P(R=0)=20/30 and P(R=1)=10/30P(R=1)=10/30. Together these calculations distinguish a joint event, a distribution with the route ignored, and a distribution within one route group. They describe the selected records; route type alone has not been established as the cause of lateness.

Worked example 10: why marginals do not determine the joint table

A training programme assesses each submitted project on two criteria: technical correctness and clarity of explanation. Code a pass as 1 and a fail as 0 for each criterion. 6. Conditionals: restrict the group, then normalize

Worked example 11: pass probability among runs with one retry

In Example 8, six IDs have exactly one retry, and three of those pass. If selection is uniform within those six IDs, the pass probability is 3/6=1/23/6=1/2.

The probability of “one retry and pass” in the full audit is 3/203/20. The probability of selecting the one-retry group is 6/206/20. Their ratio gives

P(Y=1∣X=1)=3/206/20=12.P(Y=1\mid X=1)=\frac{3/20}{6/20}=\frac12.

For events A,BA,B with P(B)>0P(B)>0, conditional probability is

P(A∣B)=P(A∩B)P(B).P(A\mid B)=\frac{P(A\cap B)}{P(B)}.

The condition changes the group to which probabilities refer. In this example, AA is the pass event and BB is the one-retry event; the numerator counts IDs satisfying both.

The conditional PMF follows:

pY∣X(y∣x)=pX,Y(x,y)pX(x),pX(x)>0.p_{Y\mid X}(y\mid x)=\frac{p_{X,Y}(x,y)}{p_X(x)},\qquad p_X(x)>0.

For a fixed xx, its probabilities over yy sum to 1. In this audit the conditional pass probabilities for x=0,1,2x=0,1,2 are 0.8,0.5,0.250.8,0.5,0.25. The conditional fail probabilities are their complements.

Reversing the condition changes the denominator:

P(X=1∣Y=1)=3/2012/20=14.P(X=1\mid Y=1)=\frac{3/20}{12/20}=\frac14.

“One retry among passes” and “pass among one-retry runs” are different questions. Conditioning on an absent group, such as X=3X=3 in this audit, cannot be computed by this ratio because its denominator is zero.

Worked example 12: recovering an overall pass probability

Combine the conditional pass probabilities using the retry-group probabilities:

P(Y=1)=P(Y=1∣X=0)pX(0)+P(Y=1∣X=1)pX(1)+P(Y=1∣X=2)pX(2)=0.8(0.5)+0.5(0.3)+0.25(0.2)=0.60.\begin{aligned} P(Y=1)&=P(Y=1\mid X=0)p_X(0)\\ &\quad+P(Y=1\mid X=1)p_X(1)+P(Y=1\mid X=2)p_X(2)\\ &=0.8(0.5)+0.5(0.3)+0.25(0.2)=0.60. \end{aligned}

pY(y)=∑x:pX(x)>0pY∣X(y∣x)pX(x).p_Y(y)=\sum_{x:p_X(x)>0}p_{Y\mid X}(y\mid x)p_X(x).

Equivalently, a joint mass can be reconstructed as pX,Y(x,y)=pY∣X(y∣x)pX(x)p_{X,Y}(x,y)=p_{Y\mid X}(y\mid x)p_X(x). Conditional rates without group weights do not determine the marginal rate.

At the event level the same rearrangement gives P(A∩B)=P(A∣B)P(B)P(A\cap B)=P(A\mid B)P(B) when P(B)>0P(B)>0. This justifies the ordered-draw rule used in Lecture 01.1: choosing uniformly from nn objects, then uniformly from the remaining n−1n-1, assigns a specified ordered pair probability (1/n)⋅(1/(n−1))(1/n)\cdot(1/(n-1)).

A nursery has completed a germination trial on 20 trays, each planted with the same number of seeds. Each tray is labelled adequately watered or dry using a recorded moisture criterion. 7. Independence is a property to check

Worked example 14: do retries and the result behave independently?

In Example 8, the overall pass probability is 0.600.60, but the pass probability given zero retries is 0.800.80. Knowing the retry count changes the distribution of the result. They are not independent under this audit-selection model.

Two events A,BA,B are independent if P(A∩B)=P(A)P(B)P(A\cap B)=P(A)P(B). For example, in the audit the events “zero retries” and “pass” have intersection probability 0.400.40, rather than 0.50⋅0.600.50\cdot0.60, so those events are dependent.

For discrete variables, independence means

pX,Y(x,y)=pX(x)pY(y)for every pair (x,y).p_{X,Y}(x,y)=p_X(x)p_Y(y)\quad\text{for every pair }(x,y).

One mismatch disproves it: pX,Y(0,1)=0.40p_{X,Y}(0,1)=0.40, whereas pX(0)pY(1)=0.50(0.60)=0.30p_X(0)p_Y(1)=0.50(0.60)=0.30. To establish independence, the factorization must hold for every pair, including pairs with zero mass. In Example 10, Model A factors for every cell; Model B does not.

For a fixed total duration xx, the inspection time ranges from 0 to xx. Integrate along that vertical slice:

NoteWhy this collection is a sigma-algebra

A sigma-algebra contains Ω\Omega and is closed under complements and countable unions. The Kolmogorov axioms hold: all event counts are nonnegative, P(Ω)=10/10=1P(\Omega)=10/10=1, and counts add over pairwise disjoint events. In a pairwise disjoint sequence of subsets of this finite space, only finitely many can be nonempty, so this also establishes countable additivity. In particular, P(⌀)=0P(\varnothing)=0.
